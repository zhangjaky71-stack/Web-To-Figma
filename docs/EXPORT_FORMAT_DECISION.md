# Export Format Decision

**Decision:** The Web-To-Figma portable package extension is `.wtf`.

**MIME:** `application/x-wtf`

**Effective:** 2026-08-21

**Scope:** Browser export, offline package storage, Figma picker/drop import, file-spec examples, fixtures, QA and release documentation.

**Unchanged:** `W2F` product naming and internal namespaces.
