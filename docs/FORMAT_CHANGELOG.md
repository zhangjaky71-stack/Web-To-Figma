# Export Format Change Log

## 2026-08-21 — Standardize export package as `.wtf`

The portable export/import package extension is now `.wtf`.

```text
.wtf
application/x-wtf
```

This change has been synchronized across the V1 historical plan, V2 baseline, V2.1 addendum, implementation status documentation, documentation index, integrity manifest, and reassembly tooling.

The `W2F` product name and internal namespaces remain unchanged.
